Multi-Tier Audio Fallback Cascade

To prevent silent failure in live classroom environments, audio playback attempts 5 sequential fallback layers before degrading gracefully to client-side speech synthesis.

Google Journey Voice Anti-Clipping Rule

Journey voices (e.g. en-US-Journey-D) start at sample 0 and do not support SSML. To prevent DAC/player startup latency from clipping initial consonants (e.g., "Plus" → "lus"):

  • Prepend 240ms MPEG-2 Layer III 24kHz silence frames (10 × 96 bytes: hex fff344c453000003480000000055...).
  • Append 288ms silence frames (12 × 96 bytes) for smooth decay.
  • Inject comma after introductory markers (e.g., Plus, I...).
Audio Cancellation Invariant

In audioPlayer.playUrl, cancel() must explicitly reject the Promise with a cancellation error and execute audio.src = '':

  • Resolving cleanly causes stopped audio promises to cascade into duplicate subsequent speech.
  • Always check cohort repeat_count (repeat_count: 2 loops bilingual sequence twice).
  • Use activeSequenceId to invalidate delayed playback.
